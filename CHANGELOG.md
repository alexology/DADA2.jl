# Changelog

## Unreleased

Filtering, dereplication, denoising, error learning, pair merging and chimera
detection are now translations of DADA2 1.36.0 and give R's results for the
same inputs (details and checks in [docs/r-parity.md](docs/r-parity.md)).
Results on real data differ from 0.3.0.

### Fidelity to DADA2 R

- `dada` ports the C++ core (`src/core.jl`): vectorized ends-free banded
  aligner, classic and homopolymer aligners, gapless shortcut, k-mer screen,
  greedy locks, budding, shuffling, abundance p-values and final correction,
  with upstream iteration order and tie-breaking.
- `learnErrors` follows R `learnErrors`: whole-file sampling up to `nbases`,
  mean qualities, a first round with maximal rates, `loessErrfun` on a
  translation of R's interpolated `loess` (`src/rloess.jl`), and rounds until
  a model repeats exactly.
- `mergePairs` ports R `mergePairs` (ends-free alignment, mismatch and indel
  limits, preferred read, `trimOverhang`, `justConcatenate`).
- Chimera detection ports `isBimera`, `isBimeraDenovo`, `isBimeraDenovoTable`
  and `removeBimeraDenovo` (`:consensus`, `:pooled`, `:per_sample`), with
  shifted alignments, indels and one-off parents.
- `filterAndTrim` removes phiX reads as R's `rm.phix=TRUE` (`isPhiX`,
  `FilterOptions(rmPhix)`, phiX genome from dada2 in `data/`).
- `derepFastq`/`dereplicate` order the uniques as R (decreasing abundance,
  ties by chunk of first appearance and sequence; new `n` option); ties
  inside `dada` depend on this order.
- Abundance p-values below 1e-292 are recomputed in log space, as R's
  `ppois`.
- Checked against R on fixtures generated by `validation/core_reference.R`,
  `learn_reference.R`, `pipeline_reference.R` and `phix_reference.R`, and on
  a real paired-end sample through the whole pipeline.

### New

- `DadaResult.clustering`: R's `$clustering` diagnostics.
- `dada(samples, err; pool=true | :pseudo)`: pooled and pseudo-pooled
  inference.
- `MergeResult.pairs`: every forward/reverse ASV pair, as R's
  `returnRejects=TRUE`.
- `dada` options of R `setDadaOpt`: `match`, `mismatch`, `gap`,
  `homopolymerGap`, `vectorizedAlignment`, `gapless`, `greedy`, `minFold`,
  `minHamming`, `minAbundance`.
- `learnErrors(...; qualityMode=:raw)` counts transitions at the original read
  qualities within R's procedure (Julia extension, not validated).
- `dada(samples, learned)` accepts an `ErrorLearningResult` for a vector of
  samples.
- `benchmark/pipeline_timing.{R,jl}` and `pipeline_compare.jl` run and
  compare the same paired-end pipeline in R and Julia.

### Breaking changes

- The earlier error learner was removed: `upstream`, `initial`, `tolerance`
  and `smoother` raise an error in `learnErrors`; the direct and linear
  smoothers remain only as internal functions for old validation scripts.
- `isBimeraDenovo(sequence, parents)` is now `isBimera`; the exact
  equal-length chimera test and its `minSegment` option were removed.
- `dada` no longer accepts `maxConsist`; uniques of 5 bases or fewer are
  rejected, as in R; qualities are rounded half away from zero.
- Uniques from `derepFastq` are in R's order instead of the order of first
  appearance.
- `DadaResult` and `MergeResult` have new fields (`clustering`, `pairs`).

### Fixes

- `learnErrors` applies `nbases` to dereplicated inputs too, taking whole
  samples until the bases exceed it, as R (DD10).
- Quality sums of dereplicated reads are widened before they could overflow
  (DD11); `threaded=false` also keeps the preparation of the uniques on the
  calling thread (DD9).
- Sequences longer than about 6,500 bases are aligned with 32-bit scores
  instead of overflowing 16-bit ones, as upstream does (DD5).
- Comparison-cache and chimera flags are no longer bit-packed vectors
  written by several tasks (DD6).
- `writeFasta` rejects empty or blank headers (DD7).
- Extended-precision sums of the error model no longer depend on the
  caller's BigFloat precision (DD8).

### Performance

- Dense k-mer counts in one matrix with a vectorized shared count; ordered
  k-mers only for pairs that pass the screen.
- Aligner buffers not cleared (as upstream), diagonal read forwards so the DP
  loop vectorizes, compact traceback while comparing.
- Comparisons stored by the parallel tasks; index-ordered comparison cache
  and one final-alignment slot per unique instead of dictionaries; uniques
  prepared in parallel.
- On a real paired-end sample (four threads) the whole pipeline took 95 s,
  against 312 s in R.
- Less memory for long or very diverse reads: mean qualities kept as exact
  integer sums (one byte per base for uniques seen once), ordered k-mers
  compared from the sequences instead of being stored, final alignments
  computed only for the uniques kept by the final test (the others do not
  enter the results) and not all held at once. On 19,000 nanopore uniques of
  2.7 kb (two threads) the peak memory fell from 3.7 GB to 2.2 GB.

### Input and output

- `FastqReader` and `readFasta` parse with FASTX.jl (new dependency); the
  public API is unchanged. Records are identical to the previous readers on
  the mock and fixture FASTQ files and on SILVA v132 (313,502 records).
  FASTX is stricter on one point: a `+` line that repeats a different
  header is rejected. Whitespace inside FASTA sequence lines is removed
  (previously an error); malformed files raise an `ArgumentError`.
- `validated_dna` (used for every FASTQ read and FASTA record) checks bytes
  with a lookup table: 17 times faster on SILVA, same accepted input and
  errors; invalid UTF-8 now raises `ArgumentError` instead of
  `InvalidCharError`. With both changes, reading a 107 MB FASTQ takes
  0.58 s instead of 1.1 s and `readFasta` on SILVA 1.2 s instead of 6.8 s.
- BioSequences 3.5 interoperability across DNA alignment, FASTQ records,
  chimera detection, taxonomy/species queries and FASTA writing.
- `readFasta(path; bio=true)` returns compact `LongDNA{4}` values while the
  default string API remains compatible.

## 0.3.0 — 2026-10-10

- Real-data CLI example for single/paired-end and sample TSV manifests,
  with shared error learning, read tracking, diagnostics and FASTA/TSV exports.

- Native direct quadratic LOESS with exposure weights, constant boundary
  rates and stable lower-degree fits for sparse quality support. The previous
  linear estimator remains selectable with `smoother=:linear`.
- FASTQ-based `learnErrors` counts transitions at original quality scores
  by default (`qualityMode=:raw`), streaming each iteration. Derep inputs
  retain mean-quality counting; FASTQ callers may select `qualityMode=:mean`.
- Error-learning results expose transition counts, inference convergence and
  quality mode; `errorDiagnostics` reports training exposures and substitutions.
- Independent R smoothing fixtures and scientific calibration comparisons,
  including shared models across five simulated samples and experimental mock.

## 0.2.1 — 2026-10-10

- Reject reads shortened below `truncLen` by quality trimming, before `trimLeft`,
  matching DADA2 R. Paired filtering rejects the entire pair if either read fails.
- Add regression tests for quality cutoff boundaries and left trimming.

## 0.2.0 — 2026-10-10

- Added preliminary scientific validation: public experimental mock community,
  30 simulated conditions, R comparison, raw metrics, protocol and figures.
  No denoiser changes were made during validation; known failures are documented.

- Reusable sparse taxonomy and species indexes via `trainTaxonomy` and `trainSpecies`.
- IUPAC reference FASTA and reverse complements; k-mers skip ambiguous positions.
- Exact species matching against fragments of longer references, using a seed index.
- Linear selection of distinct chimera parents instead of a quadratic parent-pair search.
- Constant-time center membership, cached log abundances, and no alignment of centers to themselves.
- Robust error-learning convergence calculation when transition probabilities are zero.
- Bundled upstream paired-end fixtures, integration tests and offline source archives.
- GitHub CI, source archive workflow, contribution instructions and release packaging.

## 0.1.0 — 2026-10-10

- Initial Julia pipeline: FASTQ/gzip, filtering, dereplication, ASV inference,
  error learning, merging, chimera detection, taxonomy and FASTA IO.
- Shared-error-model parity on the upstream sam1 fixture with DADA2 R 1.36.0.
